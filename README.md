# Queues Test Implementation

This repository contains implementations and tests for various queue data structures. It is designed to help understand, test, and compare the behavior and performance of different queue implementations.

## Features

- Multiple queue data structures implemented (e.g., simple queue, circular queue, priority queue, etc.)
- Comprehensive unit tests for correctness and edge cases
- Clear, modular code structure for easy navigation and extension
- Example usage provided for each queue implementation

## Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/) (if using JavaScript/TypeScript)

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/mrrajput04/queues-test-implementataion.git
   cd queues-test-implementataion
   ```

2. Install dependencies (if required, depending on language):
   - For Node.js projects:
     ```bash
     npm install
     ```
### Running Tests

- For Node.js:
  ```bash
  npm test
  ```
  
*(Modify the above commands as per your language and testing framework.)*
